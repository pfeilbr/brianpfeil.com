Besides the architecture guides, I've published a set of free, self-paced courses. Each is a series of short lessons plus a cheat sheet, built from first principles, with every example run for real. No sign-up needed.

**Cloud and infrastructure**

- [Terraform](https://brianpfeil.com/courses/terraform/): how it really works: plan, state, modules and the apply lifecycle.
- [Nix](https://brianpfeil.com/courses/nix/): reproducible builds and dev environments with derivations, the store and flakes.
- [Web Authentication](https://brianpfeil.com/courses/auth/): sessions vs tokens, OAuth2/OIDC, passwordless and passkeys, wired into a real app.
- [Stripe](https://brianpfeil.com/courses/stripe/): checkout, webhooks and subscriptions for selling digital products.

**AI and agents**

- [Agentic Loop Engineering](https://brianpfeil.com/courses/agentic-loop-engineering/): designing tight, verifiable agent loops with Claude Code.
- [Browser-Testing Playground](https://brianpfeil.com/courses/playground/): Claude Code as an autonomous end-to-end UI tester.
- [mlx-lm](https://brianpfeil.com/courses/mlx-lm/): run, quantize, serve and fine-tune LLMs locally on Apple Silicon.
- [PyTorch](https://brianpfeil.com/courses/pytorch/): tensors, autograd and the training loop, runnable on a Mac.

**Under the hood**

- [eBPF](https://brianpfeil.com/courses/ebpf/): see inside the running Linux kernel with eBPF and bpftrace.
- [V8 JavaScript Engine](https://brianpfeil.com/courses/v8-javascript-engine/): parsing, the JIT pipeline and hidden classes.
- [macOS Kernel and System Extensions](https://brianpfeil.com/courses/macos-kernel-extensions/): from legacy kexts to modern System Extensions on Apple Silicon.
- [C++ Standard Library](https://brianpfeil.com/courses/cpp-standard-library/): the classes you'll use most, so you reach for the right one by reflex.
