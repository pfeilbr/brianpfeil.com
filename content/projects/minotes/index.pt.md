Minotes — notas minimalistas — foi pensado do zero para tornar as anotações rápidas e limpas. Em vez de espremer recursos numa interface lotada, o Minotes oferece uma interface mínima e enxuta para as suas notas.

* **limpo** — A interface do Minotes é propositalmente simples. Ela entrega só o que você precisa, sem nenhuma distração
* **rápido** — O Minotes foi otimizado do zero para ser rápido e fluido, esteja você no iPhone mais novo ou num modelo mais antigo.
* **bonito** — Da navegação cuidadosamente pensada ao conjunto enxuto de ajustes, o Minotes foi desenhado para dar vontade de abrir.
