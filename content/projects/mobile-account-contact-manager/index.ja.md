バックエンドに [Salesforce](http://salesforce.com) プラットフォーム、フロントエンドに [jQuery Mobile](http://jquerymobile.com/) を使って構築した、モバイル向けの連絡先・取引先管理 Web アプリケーションです。[HTML5 Application Cache](http://www.whatwg.org/specs/web-apps/current-work/multipage/offline.html) と [local storage](http://dev.w3.org/html5/webstorage/) を利用しているので、オフラインでも同じ機能が使えます。

詳しくは [Salesforce and jQuery Mobile の記事](/post/salesforce-and-jquery-mobile/)（英語）をご覧ください。

*[ソースコード](https://github.com/pfeilbr/salesforce-jquery-mobile)*
