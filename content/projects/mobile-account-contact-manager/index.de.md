Eine mobile Web-App zur Kontakt- und Kundenverwaltung, im Backend auf der [Salesforce](http://salesforce.com)-Plattform und im Frontend auf [jQuery Mobile](http://jquerymobile.com/) aufgebaut. Dank [HTML5 Application Cache](http://www.whatwg.org/specs/web-apps/current-work/multipage/offline.html) und [local storage](http://dev.w3.org/html5/webstorage/) steht derselbe Funktionsumfang auch ohne Verbindung zur Verfügung.

Details im Beitrag [Salesforce and jQuery Mobile](/post/salesforce-and-jquery-mobile/) (englisch)
