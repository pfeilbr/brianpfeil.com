一个移动端的联系人与客户管理 Web 应用，后端使用 [Salesforce](http://salesforce.com) 平台，前端使用 [jQuery Mobile](http://jquerymobile.com/)。借助 [HTML5 Application Cache](http://www.whatwg.org/specs/web-apps/current-work/multipage/offline.html) 和 [local storage](http://dev.w3.org/html5/webstorage/)，断网状态下也能提供同样的功能。

详情见 [Salesforce and jQuery Mobile 一文](/post/salesforce-and-jquery-mobile/)（英文）

*[源代码](https://github.com/pfeilbr/salesforce-jquery-mobile)*
