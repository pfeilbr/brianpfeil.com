{{- /* The paginator for a paginated list page, or false. Hugo creates a page's paginator on the first .Paginate call and hands the same one back after that, and a page whose paginator exists gets its /page/N/ pages built. So this only asks on the two kinds of page whose templates paginate, with the same collection they use: - the /post/ section (post/list.html: partials/site-posts.html) - tag and category terms (_default/list.html: .Pages) baseof.html calls this from , before the template's own call. */ -}} {{- $p := false -}} {{- if and (eq .Kind "section") (eq .Section "post") -}} {{- $p = .Paginate (partial "site-posts.html" .) -}} {{- else if eq .Kind "term" -}} {{- $p = .Paginate .Pages -}} {{- end -}} {{- return $p -}}
