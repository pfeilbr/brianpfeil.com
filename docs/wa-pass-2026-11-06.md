## Found along the way, left for B

- **GitHub's free security features are all off** for this public repo:
  secret scanning, push protection, Dependabot security updates and private
  vulnerability reporting. Turning them on is a repo-settings change, so it
  was not done here. One command:
  `gh api -X PATCH repos/pfeilbr/brianpfeil.com --input - <<< '{"security_and_analysis":{"secret_scanning":{"status":"enabled"},"secret_scanning_push_protection":{"status":"enabled"}}}' && gh api -X PUT repos/pfeilbr/brianpfeil.com/vulnerability-alerts && gh api -X PUT repos/pfeilbr/brianpfeil.com/automated-security-fixes && gh api -X PUT repos/pfeilbr/brianpfeil.com/private-vulnerability-reporting`
- `go.mod` says `go 1.26.0`, so CI tests the generator on that exact release.
  Raising it to the current patch is a Dependabot-style bump, not done here.
